🛒 Sistem Kasir Sederhana

📌 Deskripsi

Sistem Kasir Sederhana adalah sebuah website yang dibuat menggunakan HTML untuk membantu proses transaksi pada sebuah toko. Website ini memungkinkan pengguna untuk memasukkan data barang, jumlah barang, dan menghitung total harga pembelian.

✨ Fitur

- Menampilkan daftar barang
- Memasukkan jumlah barang
- Menghitung total harga
- Menampilkan hasil transaksi
- Tampilan sederhana dan mudah digunakan

💻 Teknologi

- HTML

📂 Struktur Project

kasir/
├── index.html
└── README.md

▶️ Cara Menjalankan

1. Download atau clone repository ini.
2. Buka file "index.html".
3. Jalankan menggunakan browser seperti Google Chrome atau Microsoft Edge.

🎯 Tujuan

Project ini dibuat sebagai latihan dalam membuat website sederhana menggunakan HTML serta memahami dasar pembuatan sistem kasir.
